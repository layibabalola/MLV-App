# Security Policy

## Supported versions

Security fixes are made against the latest commit on `master`. Older revisions are not supported. When a fix affects a published binary, maintainers will publish a new release when practicable.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/layibabalola/MLV-App/security/advisories/new).

Include the affected commit or release, operating system, impact, reproduction steps or a minimal proof of concept, and any suggested mitigation. Do not include personal data or sensitive footage.

Please allow maintainers time to investigate and coordinate disclosure before publishing details.
