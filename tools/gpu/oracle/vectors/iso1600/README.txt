SYNTHETIC DUAL-ISO BAYER FORMULA (fixed, closed-form, byte-reproducible)
-----------------------------------------------------------------------
  Constants: BLACK=2047, WHITE=15000 (14-bit), span = WHITE-BLACK = 12953.
  Bright-field pattern per (y&3): is_bright = {1,1,0,0}
     (matches iso_patterns[0]; auto-detect resolves to this).

  Scene irradiance S(x,y) in [0,1] (double precision):
     gx   = x / (W-1)
     gy   = y / (H-1)
     grad = 0.5 * (gx + gy)
     tex  = 0.18 * sin( x*(2*PI/64) + y*(2*PI/48) )
     S    = clamp(grad + tex, 0, 1)

  Pixel value (14-bit), is_bright = is_bright[y&3]:
     if is_bright:  v = BLACK + S * span            (low ISO 100, ~3 EV more)
     else        :  v = BLACK + S * (span / 8)      (high ISO 800, 2^-3)
     pixel = clamp( floor(v + 0.5), BLACK, WHITE )    (uint16)

  The 8x bright/dark ratio == 3 EV == log2(800/100), so match_exposures on
  the ISO-ratio path (auto_correction=-1, ev_correction sentinel=1) computes
  corr_ev = 3.0 (>= 0.5) and matches without aborting.

  CUDA REPRODUCTION: use IEEE-754 double sin()/floor and the same rounding
  (floor(v+0.5)) to regenerate in.u16 byte-identically.
