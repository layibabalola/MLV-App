History reproduction, pinned to the audit target rather than a moving branch.
Run this Python from the repository. A full walk avoids date-traversal shortcuts;
explicit UTC epochs avoid dependence on the reader's timezone:

```python
import datetime
import subprocess

pin = "1a4f152d3536fa40b5b6018061aeeb6dd6f12d15"
raw = subprocess.check_output(
    ["git", "log", pin, "--no-merges", "--format=@@%H %ct", "--name-only"],
    text=True, encoding="utf-8",
)
rows = []
for line in raw.splitlines():
    if line.startswith("@@"):
        sha, epoch = line[2:].split()
        rows.append({"sha": sha, "epoch": int(epoch), "source": False})
    elif rows and line.startswith(("src/", "platform/")):
        rows[-1]["source"] = True
start = int(datetime.datetime(2026, 8, 29, tzinfo=datetime.timezone.utc).timestamp())
selected = [row for row in rows if row["epoch"] >= start]
print({"commits": len(selected), "source_touch": sum(r["source"] for r in selected)})
```

Retain the command/version/window when refreshing. Do not
substitute `--all`, count `tools/` as delivered product, or treat source commits as
